What’s the difference? Semantics (strong) is used to indicate that the text is fundamentally or semanticallyimportant to the surrounding text, while (b) Bold indicates no such importance and simply represents text that should be bolded.

If you were to use (b) a text-to-speech program would not say the word(s) any differently than any of the other words around it - you are simply drawing attention to them without adding any additional importance. By using (strong) , though, the same program would want to speak those word(s) with a different tone of voice to convey that the text is important in some way

Chapter 4 - Anchors & Hyperlinks

Parameters Details
href Specifies the destination address. It can be an absolute or relative URL, or the name of an anchor. An absolute URL is the complete URL of a website like http://example.com/. A relative URL points to another directory and/or document inside the same website, e.g. /about-us/ points to the directory “about-us” inside the root directory (/). When pointing to another directory without explicitly specifying the document, web servers typically return the document “index.html” inside that directory.
hreflang Specifies the language of the resource linked by the href attribute (which must be present with this one). use language values from BCP 47 for HTML5 and RFC 1766 for HTML 4.
rel Specifies the relationship between the current decoment and the linked document. for HTML5, the values must be defined in the specification or registered in the microformats wiki .
target specifies where to open the link, e.g. in a new tab or window. possible values are _blank, _self, _parent, _top and framename (deprecated). forcing such behaviour is not recommended since it violates the control of the user over a website.
title specifies extra information about a link. The information is most often shown as a tooltip Text when the cursor moves over the link . THis attributes is note retrickted to links, it can be used on almost all HTML tags.
download Specifies that the target will be downloaded when a user clicks on the hyperlink. The Value of the attribute will be the name of the downloaded file. There are on restrictions on allowed values, and the browser will automatically detect the correct file extension and add it to the file (.img, .pdf, etc.) if the values is ommited, the original filename is used.


4.1 Link to another site

This is the basic use of the (a href="http://example.com/") element:

(a href="http://example.com/) Link to example.com (/a) then output is Link to example.com


To denote that this link leads to an external website, you can use the external link type:

(a href="http://example.com/ rel="external") Link to example site (/a) then output is Link to example site


You can link to a site that uses a protocol other that HTTP. For example, to link to an FTP site, you can do,

(a href="ftp:example.com/") This could be a link to a FTP site(/a)

In this case, the difference is that this anchor tag is requesting that the user's browser connect to example.com using the File Transfer Protocol (FTP) rather than the Hypertext Transfer Protocol (HTTP).

(a href="http://FTPsite.com/") This Could be a link to a FTP site (/a) then output is This Could be a link to a FTP site

SECURITY VULNERABILITY WARNING!

Using target ="_blank" gives the opening site partial access to the window.opener object via JavaScript, which allows that page to then access and change the window.opener.location of your page and potentiallu redirect users to malware or phising sites

whenever using this for pages you do not control, add rel ="noopener" to your link to prevent the window.opener object from being sent with the request.

Currently, firefox does not support noopener, so you will need to use rel="noopener noreforrer" for maximum effect

4.6 Link that runs JavaScript

simply use the Javascript : protocol to run the text as Javascript instead of opening it as a normal link:

(a href="javascript :myFunction()") Run code (/a) then output is Run code

You can also achieve the same thing using the onclick attribute:

(a href="#" onclick="myFunction(); return false;") Run Code (/a) Then Output is Run Code

The return false; is necessary to prevent your page from scrolling to the top when the link to # is clicked. make sure to include all code you'd like to run before it, as returning will stop execution of further code.

Also noteworthy, you can include an exclamation mark ! after the hastag in order to prevent the page from scrolling to the top. This works because any invalid slug will cause the link to not scroll anywhere on the page, because it couldn't locate the element it references (an element with id="!"). You could also just use any invalid slug (such as #scrollsNowhere) to achieve the same effect. In his case, return false; is not required:

(a href="#!" onclick="myFunction();") Run Code (/a) Then output is Run Code

5.1 - Ordered List

An ordered list can be created with the (ol) tag and each list them can be created with (li) tag as in the example below:

(ol)
 (li) Item (/li)
 (li) Another item (/li)
 (li) Yet Another item (/li)
(/ol)

Then Output is:

This will Produce a numbered list (which is the default style):

  1. Item
  2. Another item
  3. Yet Another item

Manually Changing the numbers

There are a couple of ways you can play with which numbers appear on the list items in ordered list. The first ways is to set a starting number, using the start attribute. The list will start at this defined number, and continue incrementing by on as usual

(ol start="3")
 (li) Item (/li)
 (li) Another item (/li)
 (li) Yet Another item (/li)
(/ol)

Then Output is:

This will Produce a numbered list (which is the default style):

  1. Item
  2. Some Other item
  3. Yet Another item

You can also explicitly set a certain list item to a specific number. Further list items after one with a specified value will continue incrementing by one from that list item's value, ignoring where the parent list was at.

(li value="7") Value (/li)

Then Output is:

  • Value

    • It is also worth nothing that, by using the value attribute directly on a list them, you can override an ordered list's existing numbering system by restarting the numbering at a lower value. So if the parent list was already up to value 7, and encountered a list item at value 4, then that list ite, would still display as 4 and continue counting from that point again.

    (ol start="5")
     (li) Item (li)
     (li) Some other item (/li)
     (li value="4") A Reset item (/li)
    (li) Yet other item (/li>)

    Then Output is:

    1. Item
    2. Some other item
    3. A Reset item
    4. Yet other item

    So the example above will produce a list that follows the numbering pattern of 5, 6, 4, 5, 6 - starting again at a number lower that the provious and duplicating the number 6 in the list.
    Note: The start and value attributes only accept a number - even if the ordered list is tset to display as Roman numerals or letters.

    version ≥ 5

    You can reverse the numbering by adding reversed in your ol element:

    (ol Reversed)
     (li) Item (li)
     (li) Some other item (/li)
     (li value="4") A Reset item (/li)
     (li) Yet other item (/li>)

    Then Output is:

    1. Item
    2. Some Other Item
    3. A Reset Item
    4. Yet Other Item

    Reversed numbering is helpful if you're continually adding to a list, such as with new podcast episodes or presentations, abd you want the most recenty items appear first.

    5.3 - Nested List

    You can nest lists to represent sub-item of a list item.

    (ul)
     (li) Item 1 (/li)
     (li) Item 2
      (ul)
       (li) Sub-Item 2.1 (/li)
       (li) Sub-Item 2.2 (/li)
      (/ul)
     (/li)
     (li) Item 3 (/li)
    (/ul)

    Then Output is:

    • Item 1
    • Item 2
      • Sub-Item 2.1
      • Sub-Item 2.2
    • Item 3

    The nested list had to be a child of the li element.

    You can nest different types of list, too:

    (ol)
     (li) Hello, List! (/li)
      (li)
       (ul)
        (li) Hello, nested list! (/li)
       (/ul)
      (/li)
    (/ol)

    Then Output is:
    1. Hello, List!
      • Hello, nested list!

    5.4 - Description List

    A Description list (or definition list, as it was called before HTML 5) can be created with the dl elementt. it consists if name-value groups, where the name is given in the dt element, and the value is given in the dd element.

    (dl)
     (dt) name 1 (/dt)
     (dd) Value for 1 (dd)
     (dt) name 2 (/dt)
     (dd) Value for 2 (/dd)
    (/dl)

    Then Output Is:

    name 1
    Value for 1
    name 2
    Value for 2

    A name-value group can have more than one name and/or more than one value (which represent alternatives):

    (dl)
    (dt) name 1 (/dt>)
    (dt) name 2 (/dt)
    (dd) Value for 1 & 2 (/dd)

    (dt) name 3 (/dt)
    (dd) Value for 3 (/dd)
    (dd) Value for 3 (/dd)
    (/dl)

    Then Output Is:

    name 1
    name 2
    Value for 1 & 2
    name 3
    Value for 3
    Value for 3
