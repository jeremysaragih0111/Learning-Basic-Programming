24.2 - Changing the color of a progress bar

Progress bar can be styled with the progress [value] selector.

This example gives a progress bar a width of 250px and a hight of 20px

progress: [value] {
 width: 250px;
 height: 20px;
}

Progress bars can be especially difficult to style.

Chrome/Safari/Opera

These browsers use the -webkit-appearance selector to style the progress tag. To override thism we can reset the appearance.

progress[value] {
 -webkit appearance: none;
 appearance: none;
}

Now, we can style the container itself

progress[value] {
 background-color: "green";
}


Firefox

Firefox styles the progress bar little differently. We have to use these styles

Progress[value] {
 -moz-appearance: none;
  appearance: none;
  border: none;     /*Firefox also renders a border*/
}


Internet Explorer

Internet Explorer 10+ supports the progress element. However, it does not support the background-color property. You'll need to use te color property instead.

progress[value] {
 -webkit-appearance: none;
  -moz-appearance: none;
   appearance: none;
 border: none;       /*Remove &border from firefox*/

 width:250px;
 height: 20px;

 color: blue;
}

Multi-option Selection menus

By default, user can only select a single option. Adding the multiple attribute allows users to select multiple options at once and submit all selected options with the form. Using the multiple attribute automatically convert the drop-down menu into a boz as if it had a size defined. The default size when this occurs is determined by the specific browser you are using, and it is not possible to change it back to a drop-down style menu while allowing multiple selections.

25.3 - Option Group

You can neatly group your options within a selection menu in order to provide a more structured layout in a long list of options by using the (optgroup) element.

The syntax is very basic, by simply using the element with a label attribute to identify the title for the group, and containing zero more options that should be within that group.

Input this code is:

(select name="")
 (option value="milk") Milk (/option)
 (optgroup label="Fruits")
  (option value="banana") Bananas (/option)
  (option value="strawberry") Strawberries (/option)
 (/optgroup)
 (optgroup label="Vegetables" disabled="disabled")
  (option value="carrot") carrots (/option)
  (option value="zucchini") zucchini (/option>)
 (/optgroup)
