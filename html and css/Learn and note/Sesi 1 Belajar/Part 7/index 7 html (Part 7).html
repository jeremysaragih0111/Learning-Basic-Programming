Chapter 31 - Meta Information

Meta tags in HTML document provide useful information about the document including a description, keywords, and author, dates of modification, and around 90 other fields. The topic cover the usage and purpose of these tags.

31.1 - Page Information

Meta tags are used to provide metadata about the HTML document. They are placed in the head section of the document and are not displayed on the webpage itself. Instead, they provide information to browsers, search engines, and other web services about the content and structure of the page.

Then Output:

The description meta tag can be used by various search engines while indexing your page for searching purpose. Usually, the description contained within the meta tag is the short summary that shows up under the page/webiste's main title in the search engine results. Google usually uses only the first 20-25 words of your description.

31.2 - Character Encoding

The charset attribute specifies the character encoding for the HTML document and needs to be a valid character encoding (examples includes windows-1252, ISO-8859-2, Shift_JTS, and UTF-8). UTF-8 is the most widely used and should be used for any new project.

Input this code is:

(meta charset="UTF-8") (meta charset="ISO-8859-1")

All the browsers have always recognized the (meta charset) form, but if you for some reason need your page to be valid HTML 4.01, you can use the following instead:

(meta http-equiv="Content-Type" content="text/html; charset=UTF-8") (meta http-equiv="Content-Type" content="text/html; charset=ISO-8859-1")

See also the Encoding Standard, to view all available character encodings labels that browser recognize.

31.3 - Robots

The robots attribute, supported by several major search engines, controls whether search engine spiders are allowed to index a page or not and whether they should follow links from a page or not.

Input this code is:

(meta name="robots" content="noindex")

Then Output:


The example instructs all search engines to not show the page in search results. Other allowed values are:

Value/Directive Meaning
all Default.Equivalent to index, follow. See note below.
noindex Do not index the page all.
nofollow Do not follow the links on this page.
follow The links on the page can be followed. See note below.
none Equivalent to noindex, nofollow.
noarchieve Do not make a cached version of this page available in search results.
noache Synonym of noarchive used by some bots such as bing.
nosnippet Do not show a snippet if this page in search results.
noodp Do not use metadata of this page from the Open Directory project for titles for snippets in search results.
notranslate Do not offer translation of this page in search results.
noimageindex Do not index image on this page.
unavailable_after [RFC-850 date/time] Do not show this page in search results after the specified date/time. The date/time must be specified in the RFC 850 format.

Note: Explicitly defining index and/or follow, while valid values, is not necessary as prettty much all search engines will asume they are allow to do so if not explicitly prevented from doing so. Similar to how the robots.txt file operates, search engines generally only look for things they are not allowed to do. only stating things a search engin isn't allowed to do also prevents accidentally stating opposites (sucg as index, ..., noindex) which not all search engines will treat in the same way.

31.5 - Mobile Layout Control

Common mobile-optimized sites use the (meta name="viewport") tag like this:

Input this code is:

(meta name="viewport" content="width=device-width, initial-scale=1.0")

The Viewport element gives the browsers instructions on how to conttrol the page's dimensions and scalling based on the device you are using.

In the above example, content="width=device-width, means that the browser will render the width of the page at the width of its own screen. So if that screen is 480px wide. Initial-scale-1 depicts that the initial zoom (which is 1 in this case, means it does not zoom)

Belwo are the attributes this tag supports:


Attribute Description
width The width of the virtual viewport of the device.
Values 1: Device-width or the actual width in pixels like 480
height The height of the virtual viewport of the device.
Values 2: Device-width or the actual height in pixels like 600
initial-scale The initial zoom when the page is loaded. 1.0 does not zoom
minimum-scale The minimum amount the visitor can zoom on the page. 1.0 does not zoom
maximum-scale The maximum amount the visitor can zoom on the page. 1.0 does not zoom
user-scalable Allows the device to zoom ini and out. Values are yes or no. If set to no, the user is not able to zoom in the webpage. The default is yes. Browser settings can ignore this rules.

Notes:

  • The width property can be either specified in pixels (width-600) or by device-width (width-device-width) which represents the physical width of the device's screen.
  • Similarly the height property can be either specified in pixels (height-600) or by device-height (height-device-height) which represents the physical height of the device's screen.

31.6 - Automatic Refresh

TO refresh the page every 5 seconds, add this meta element in the head element:

(meta http-equiv="refresh" content="5")

CAUTION! While this is a valid command, it is recommended that you do not use it because of its negatve effects on user experienc. Refreshing the page too often can cause it to become unresponsive, and often scrolls to the top of the page. If some information on the page needs to be updated continuously, there are much better ways to do that by only refreshing a portion of a page.


31.7 - Phone Number Recognition

Mobile platform like iOS automatically recognize phone numbers and turn them into tel: links. While the feauture is very practical, the system sometimes detects ISBN codes and other numbers as telephone numbers.

For mobile safari and some other Webkit-based mobile browsers to turn off automatic phone number recognition and formatting, you need this meta tag:

(meta name="format-detection" content="telephone=no")


31.8 - Automatic Redirect

Sometimes your website needs a automatic redirect.

For example, to redirect to example.com after 5 second:

(meta http-equiv="refresh" content="5; url=https://example.com")

This is line will send you to the designed website (in this case example.com after 5 seconds).

If you need to change the time delay before a redirect, simply changing the number rigtht before your ;url=will after the time delay.

Chapter 33 - Marking-up Quotes

33.1 - Inline with <q>

The q element can be used for a quote that is part of a sentence

<p>She wrote <q> The answer is 42. </q>and everyone agreed</p>

Quotation marks

Version ≤ 4.01

Quotation marks should not be added. User agents should (in HTML 4.01) resp. must(in HTML 4.0) render them automatically

Version ≤ 5

Quotation marks must not be added. User agents will render them automatically.

Source URL (cite attribute)

<p> She wrote <q cite="http://example.com/blog/hello-world"> The answer is 42.</q> and everyone agreed.

Note that browsers typically don't show this URL, so if the source is relevant, you should add a hyperlink (a element) in addition.
