The following embeds an untrusted web page all restrictions enabled

Input this code is:

Then Output code is:

To allow the page to run scripts and submit forms, add allow-script and allow-forms to the sandbox attribute.

Input this code is:

Then Output code is:

If there is untrusted content (such as user comments) on the same doamin as the parent web page, an inframe can be used to disable scripts while still allowing the parent document to interact with it's content using JavaScript.

Input this code is:

(iframe src="http://example.com/untrusted/comments/page2" sandbox="allow-same-origin allow-top-navigation")

Then Output code is:

The parent document can add event listeners and resize the IFrame to fit its contents. This, along with allow allow-top-navigation, can make the sandboxed iframe appear to be part of parent document.

This sandbox is not a replacement for sanitizing input but can be used as part of a defense in depth strategy.

Also be aware that this sandbox can be subverted by an attacker convicing a user to visit the iframe's source directly. The Content Security Policy HTTP header can be used to mitigate this attack.

Chapter 28 - Content Languages

28.1 - Base Document Language

It's a good practice to declare the primary language of the document in the HTML element:

If no other lang attribute is specified in the document, it means that everything (i.e., element content and attribute text values) is in that language.

If the document containts parts in others languages, these parts should get their own lang attributes to "overwrite" the language declaration.


28.2 - Element language

The lang attribute is used to specify the language of element content and attribute text values:

Input this code:

(p lang="en") The content of this element is in English (/p)
(p lang="en" title="The value of this attribute is also in English") The content of this element is English (/p)

Then Output code is:

The content of this element is in English

The content of this element is English


The language declaration gets inherited:

Input this code is:

(div lang="en")
 (p) This element containts English content. (/p)
 (p title="This attribute, too.") Same with this element(/p)
(/div)

Then Output code is:

This element contains English content.

Same with this element


28.3 - Elements with Multiple Languages

You can "overwrite" a language declaration:

Input this code is:

(p lang="en") This English sentence contains the the German word (span lang="de") Hallo

Then Output code is:

This English sentence contains the German word Hallo


28.4 - Regional URLs

It is possible to add the attribute hreflang to the elements (a) and (area) that create hyperlinks. Such it specifies the language of the linked resource. The language defined must be a valid BCP 47 (1) language tag.

Input this code is:

example.orgis one of IANA's example domains.

Then Output code is:

example.orgis one of IANA's example domains.

1. ↑ IETF Networking Group: RFC 5646 Tags for identifying languages IETF, September 2009


28.5 - Handling Attributes with Different Languages

You can "overwrite" parent element's language declaration by introducing any element apart from applet, base, basefont, br, frame, frameset, hr, iframe, meta, param, script (of HTML 4.0) with an own lang attribute:
